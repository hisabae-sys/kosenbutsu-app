# kosenbutsu-app

候補・議員が、公明ニュースと後援会通信を自分で作り、入稿用PDFまで仕上げるためのアプリです。

## いまできること（試作）

- 公明ニュース外面（A4横・二つ折り、塗り足し3mm）の入力とプレビュー
- 表記の自動チェック
  - 生年月日から「○YYYY年M月D日生まれ〈NN歳〉」を作る（年齢は2027年4月1日時点）
  - 学歴を「～小学校、～中学校、～高校卒、～大学卒」にそろえ、「国立・県立・町立・村立」を外す
  - プロフィールの行頭を「○」（U+25CB）にそろえる
  - 半角の「!」「?」を全角にする、数字と単位の間のスペースを取る
  - 期数を「（現在N期目）」にする
  - 枠からあふれた文字、写真の画質不足（300dpi未満）、URLの誤りを知らせる
- 枠に入りきらない文字は7割まで自動で小さくする
- QRコードの自動作成
- 政策（チャレンジ）の追加・削除（5つまで）
- 「公明ニュース」「TOKUSHIMA」「〇〇特集」「のチャレンジ」などの固定の文字もすべて編集できる
- プレビューの文字や写真を押すと、その場で編集できる
- 「デザイン」タブ：要素を選び、位置（ドラッグでも可）・大きさ・フォント・文字の大きさ・色・太字・斜体・縦横・揃え・行間・字間・表示/非表示を変える。要素ごと・全体の「標準に戻す」
- 「書類の設定」タブ：種類、用紙・印刷の仕様、仕上がり線の表示、テーマ色
- プレビューの拡大・縮小（Ctrl＋ホイールでも可）。スマホではプレビューを上に固定
- 原稿の書き出し・読み込み（JSON。デザイン設定も含む）

入力した内容は、使っている端末のブラウザ内に保存されます。

## まだできないこと

- Googleログインとドライブへの保存
- CMYKの入稿用PDF（いまの「印刷用に保存」はブラウザの印刷機能を使った仮のもの）
- 中面、後援会通信（かじわら一哉通信の型）
- 公明党ロゴなどの素材の差し込み

## 動かし方

静的なページなので、GitHub Pagesでそのまま公開できます。手元で見るときは次の通りです。

```
python3 -m http.server 8000
# http://localhost:8000/ を開く
```

テスト：`npm test`

## 注意

実在の候補・議員の個人情報や写真は、このリポジトリに入れないでください（公開リポジトリのため）。見本データは架空の人物です。
